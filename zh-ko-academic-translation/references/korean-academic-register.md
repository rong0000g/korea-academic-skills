# 韩语学术语体要点与中国学习者常见错误

## 1. 实证研究：中国学习者韩语学位论文的错误分布
장현묵（2026）分析了首尔某大学论文校对服务收集的 **137 篇**中国学习者韩语学位论文，对照校对前后共 **18,590 处**错误：[1]
- **문어적 격식성（书面正式性）错误 73.7%**：最多的是**口语/非正式表达（37.2%）**，其次为不当词汇与表达、人称代词、句末语尾。
- **논리적 호응（逻辑呼应）错误 26.3%**：最多的是**指代对象不明确（42.9%）**，其次为主谓呼应、逻辑连接表达、其他逻辑展开问题。

→ 润色时按这一顺序优先检查。

## 2. 句末与推测表达
- 学术书面语以「-다」体终结（平叙、断言）。[2]
- 推测/可能性：「-(으)ㄹ 것이다」使用范围最广；在更正式的书面语中「-을 것으로 예상되다」「-을 것으로 보이다」更常见。[3]

## 3. 客观化策略
- 被动等表达在学术文本中用于把焦点放在对象/事件上、拉开研究者与结论的距离，是实现客观性的策略。[4]
- 已有研究比较了韩语学习者与母语者在学术写作中使用客观化策略的差异（见 [5]），润色时可参考，但不机械地把所有主动句改成被动句。

## 4. 检查清单（由上述来源归纳）
- [ ] 删除或替换口语表达、缩略形式和非正式连接词。
- [ ] 句末统一为书面「-다」体；推测用适当的正式表达。
- [ ] 减少「나/저/우리」等人称代词，改用「본 연구」「연구자」等（以学科惯例为准）。
- [ ] 每个「이/그/이러한」都能明确指向前文对象。
- [ ] 主语与谓语呼应；长句拆分。
- [ ] 连接词（따라서、그러나、즉 等）与真实逻辑关系一致。
