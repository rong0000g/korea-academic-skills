# 中文 → 韩文学术翻译与润色

开始前完整读取 [references/korean-academic-register.md](references/korean-academic-register.md)。

## 工作流程

1. 确认交付物类型（학위논문 본문、국문초록、KCI 投稿论文、投稿信）、学科以及目标期刊/学校是否有用语规范。
2. **忠实优先：** 不增删论点、数据、引文；术语首次出现时可附原文或英文（按学校/期刊规范）。无法确定的韩文术语标为“待确认”，并给出 1–2 个候选，不自行“定稿”。
3. **按参考文件逐项检查语体**，重点处理中国学习者高频问题：口语/非正式表达、不当词汇、人称代词、句末语尾、指代不明、主谓不呼应、逻辑连接词不当。
4. **输出三栏：** 原文 / 修改后 / 修改理由（对应参考文件中的问题类型）。末尾列出需要作者或韩语母语者确认的条目。
5. 最终稿建议交由学校的论文校对服务、导师或韩语母语研究者复核。

## 边界

- 不代写研究内容，不以“规避 AI 检测”为目标。
- 学校/期刊对汉字并记、外来语、引用格式等有不同规定，以其规范为准。
