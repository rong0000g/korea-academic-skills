# 学位论文格式与提交检查

开始前完整读取 [references/format-guidelines.md](references/format-guidelines.md) 和 [references/plagiarism-check.md](references/plagiarism-check.md)。

## 工作流程

1. **索取本校 작성 지침**（대학원 홈페이지 공지/서식）。若用户没有，提醒各校规定不同，只能用参考文件中的公开示例做“常见项目”初查，并把每条标为“待按本校规定确认”。
2. **结构检查：** 封面、속표지、제출지、인준지、目录（含表/图目录）、국문초록、正文、参考文献、Abstract、附录的顺序与有无；初录位置（国文初录在前或后）按本校规定。
3. **版式检查：** 纸张、页边距、字体字号、行距、标题层级编号、页码（前置页罗马小写、正文阿拉伯数字等）、表题在上/图题在下、编号规则。能从文件读出的给出实测值；读不出的列为人工核对项。
4. **伦理与查重：** 说明本校使用 KCI 문헌유사도검사、카피킬러캠퍼스 或 Turnitin 中的哪一个，检查设置（排除引用句、出处标注句、目录/参考文献；判定单位等）与所需的결과확인서类型；提示相似度阈值由学校规定。
5. **输出：** 问题表（位置 / 现状 / 规定依据 / 修改建议）+ 提交材料清单（연구윤리 서약서、표절검사 결과확인서 等，以本校为准）。

## 边界

- 相似度数字不等于是否抄袭的判断；不提供“降重”改写以规避检测。
- 本 Skill 不能代替学校的格式审查。
