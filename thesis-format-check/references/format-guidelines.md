# 韩国大学学位论文作成指针：公开示例

> **各校差异很大，以下数值互相矛盾是正常的。** 一律以本校最新「학위논문 작성 지침」为准。

## 结构顺序示例
- 동서대학교：겉표지 → 표지 배면 → 속표지 → 인준서 → 목차 → 국문초록 → 본문 → 참고문헌 → Abstract → 부록/색인；国文初录放在目录前，英文 Abstract 放在参考文献后。[1]
- 인천대학교 정책대학원：표지 → 속표지 → 제출지 → 인준지 → 감사의 글 → 국문초록 → 목차 → 표목차 → 그림목차 → 본문 → 참고문헌 → ABSTRACT；正文为英文时 ABSTRACT 在前、国文初录在后。[4]
- 충남대학교：国文论文须在参考文献后附外文初录，外文论文附国文初录；初录另起一页。[3]
- 서울대 암연구소：国文/外文初录都要写；初录长度 2–7 页。[2]

## 页码与编号
- 동서대：表紙到인준서不标页码；目录到国文初录用罗马小写（-ⅰ-）；正文起用阿拉伯数字（- 1 -）。[1]
- 인천대：表/图按章编号（표 1.1、그림 2.1）；表题在表上方居中，图题在图下方居中。[4]
- 충남대：一级标题居中 16pt 加粗、二级 14pt 加粗（HY신명조）；论文题目原则上不加副题。[3]

## 인준지
- 서울대 암연구소：签名/盖章硕士 3 人、博士 5 人（含委员长）；指导教授不能任委员长。[2]
- 인천대 정책대학원（硕士）：심사위원 3 人，委员长在最上方。[4]
