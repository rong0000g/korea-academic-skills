# 审查委员常见问题与回答结构

## 1. 问题的五个来源（프라임 컨설팅整理）[1]
| 来源 | 委员的疑问 | 常见问题 |
| --- | --- | --- |
| 主题必要性 (Why this?) | 已知的内容为什么还要研究？ | 与先行研究相比本研究的差异是什么？ |
| 研究对象与样本 (Why them?) | 样本是否便利抽样、能否代表总体？ | 为什么限定该地区/群体？样本量依据是什么？ |
| 方法与测量 (How?) | 是否有效测量概念、是否检验统计前提？ | 为什么选这个量表/方法而不是其他？正态性、多重共线性不满足怎么办？ |
| 结果解释 (So what?) | 是否理解数值的含义？ | 假设被拒绝的原因？与先行研究相反如何解释？ |
| 局限与启示 (Now what?) | 是否意识到适用范围？ | 最大的方法论局限是什么？后续研究方向？ |
同一来源称：在 프로포절 심사 阶段，前三类问题约占 80%。[1]

## 2. 回答三段式 [1]
1. 先给结论（为什么这样选）；2. 用先行研究/证据支撑；3. 主动承认局限并说明已写入「연구의 제한점」。

## 3. 其他高频问题
- 研究目的：应能给出一句话、1 分钟、5 分钟三个版本的回答。[2]
- 研究动机、理论/概念框架、方法选择及被排除的替代方案、样本与工具、学术贡献、自我批评（“如果重做会改什么”）。[3]
- 国际上常用的练习题（McGill）：为什么选这个题目、如何形成概念框架和研究设计、结论的可推广性、对知识的贡献、你会如何批评自己的论文、拿到学位后做什么。[4]
- 写作形式、格式与参考文献也常被指出。[2]

## 4. 准备
- 预期问答清单约 15–20 题，整理成 A4 2–3 页；该来源称答辩时放在讲台上参考不属于违规——**但请以本校规定为准**。[1]
- 不要整句背诵答案；标好重要表、图、数字的页码；出声模拟练习。[3]
- 时间表示例：D-30 通读并按类型整理答案逻辑；D-14 了解委员研究方向、第一次模拟；D-7 定稿 PPT、整理页码索引；D-3 第二次模拟；D-1 彩排。[3]

## 5. 格式事实（因校而异）
- 例：首尔大学癌研究所大学院规定인준지签名硕士 3 人、博士 5 人（含委员长），指导教授不能任委员长。[5]
