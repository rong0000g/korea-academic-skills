# KCI / SSCI 选刊（面向在韩研究生）

开始前完整读取 [references/kci-system.md](references/kci-system.md) 和 [references/graduation-requirements.md](references/graduation-requirements.md)。

## 工作流程

1. **先问清毕业要求，再谈选刊。** 询问用户的学校、大学院、学科、学位（硕士/博士）和入学年度。告诉用户：论文发表要求由各校「대학원 시행세칙」和「학과 내규」决定，并且常按入学年度变化；必须以本人所在学科的最新内规为准。不要替用户假定“KCI 一篇就够”。
2. **把要求拆成可核对的条件：** 期刊等级（SCIE/SSCI/A&HCI、SCOPUS、KCI 우수등재/등재/등재후보）、篇数或积分、作者身份（单独/제1저자/교신저자/공동저자）、是否须在入学后发表并标明本校所属、是否接受 게재예정증명서 或 acceptance letter。
3. **核验期刊等级。** 指导用户在 kci.go.kr 按刊名或 ISSN 检索并查看「등재구분」；SSCI/SCIE 在 Clarivate Master Journal List 核验。等级每年可能变化，给出的任何等级都必须注明“需在官网当日核验”。
4. **按研究匹配度建梯队。** 依据用户论文主题、方法和近期同类论文，列出冲刺—匹配—保底候选，并说明每本期刊满足/不满足毕业要求的哪一条。不得编造期刊名、审稿周期、版面费或录用率；拿不到数据就写“未核实”。
5. **输出**：毕业要求核对表 + 候选期刊表（刊名、등재구분及核验来源、匹配理由、未核实项）+ 下一步要向学科办公室或导师确认的问题清单。

## 边界

- 不承诺录用，不推荐掠夺性期刊，不建议一稿多投。
- 规则因校、因学科、因入学年度而异；本 Skill 提供的是核对框架和公开示例，不是任何学校的官方解释。
